# 修改记录

本文件是「有秋（Yield）」的主变更档案：上半部分是**版本记录**（面向使用者的版本历史，发布 Release 时同步维护），下半部分是**修改记录**（面向开发者的逐次改动档案）。

- **当前版本**：v1.0.10（`package.json` / `src-tauri/tauri.conf.json`）
- **相关文档**：`README.md`（产品说明）、`docs/ARCHITECTURE.md`（架构与技术栈）、`docs/GIT_CONVENTIONS.md`（推送与发布惯例）

## 记录约定

1. **倒序追加**：最新条目放在对应区域的最上面。
2. **条目完整**：每条包含类型、改动内容(涉及文件,尽量标注函数/行号)、原因、影响、验证方式。
3. **数据库变更单独强调**：涉及 SQLite 表结构或 migration 时,必须在「影响」中注明 migration 编号,并确认 `src/lib/db/` 的迁移逻辑同步更新。数据库结构只支持向前升级,不支持降级。
4. **README 同步**：影响用户可感知行为的修改,需同步更新 `README.md` 的功能描述;若发布新版本,版本号需同步改 `package.json`、`src-tauri/tauri.conf.json` 与 `src-tauri/Cargo.toml`,并在本文件「版本记录」区追加条目。
5. **验证后才算完成**：条目落笔前至少跑 `npx tsc --noEmit` + `npx vitest run` + `npx vite build`;涉及 Rust 的改动加 `cargo check`;界面改动需在模拟器/实机验证。
6. **改动必须彻底,杜绝代码空放**：任何功能改动都要前后端同步——删除或替换一个功能时,必须同步删除其对应的后端逻辑、数据库读写、store 方法、lib 纯函数、样式与无用导出,不允许留下只被前端引用或只被后端定义的"半截"代码;新增逻辑同理,分层职责要完整。`npx tsc --noUnusedLocals` 只能查局部未用变量,无用导出需人工 grep 确认零引用。

## 条目模板

```markdown
### YYYY-MM-DD · 一句话标题

- **类型**:功能 / 修复 / 重构 / 配置 / 文档 / 环境
- **改动**:`文件路径` — 改了什么(函数名或行号)
- **原因**:为什么要改
- **影响**:对数据结构 / 兼容性 / 其他模块的影响;无则写「无」
- **验证**:门禁结果、手动验证步骤
```

## 版本记录

#### v1.0.10 新建抽屉统一、编辑表单修正与时间轴拖动

- 待办箱新建任务与今日新建完全一致：时间安排（开始/截止时间）不再等选完日期才出现，未选日期时填写的时间也会随任务保存
- 修复编辑任务表单里出现两个「标签」下拉的问题（上一版重排行时误留了旧字段）
- 当日时间轴支持横向拖动任务块改时间：整块即手柄、无显性拖动条，按 15 分钟对齐，时长不变；微动（<4px）仍视为点击打开详情；已完成任务不可拖动
- 数据结构无变化，桌面端与 Android 端同步更新，可直接覆盖安装

#### v1.0.9 新建/编辑任务瘦身与预计时长下线

- 「编辑任务」删除「完成标准」「备注」两个字段；「优先级」与「所属项目」并为一行，「重复」与「标签」并为一行，表单更紧凑
- 待办箱新建任务补上「重复」选择，与今日新建一致；两处新建任务抽屉删除「预计时长」，日期选择移入「时间安排」卡片并重排布局（日期在上，开始/截止时间在下，未选日期时不显示时间行）
- 「预计时长」概念从应用中彻底移除：任务列表/时间轴悬浮不再显示时长；无结束时间的任务在时间轴上按 1 小时占位；数据库 `task_planning_metadata.estimated_minutes` 列随 migration v8 删除（数据库只向前升级，旧数据无损，同步/备份兼容旧记录）
- 任务详情右上角不再有「编辑」入口（编辑统一走底部按钮）；底部按钮改为满行布局：主按钮（完成/保存）稍宽，「取消/编辑」带浅色底与描边，「删除任务」改为红底白字
- 桌面端与 Android 端同步更新，可直接覆盖安装

#### v1.0.8 界面残留清理与成长记录口径修正

- 任务详情底部移除残留的「开始专注」按钮（番茄钟功能此前已删除），「完成」接替为主按钮
- 标签页的任务列表完成态从「划去置灰」改为与应用其他位置一致的金色成就式（✓ 金章、暖金底，含暗色适配），不再划线置灰
- 成长页热力图改按任务自身的日期（截止日）点亮，不再按完成时刻：补记或延后完成的任务会落在它所属的那一天；无日期的任务回退到完成时刻
- 数据结构无变化，桌面端与 Android 端同步更新，可直接覆盖安装

#### v1.0.7 底部导航互斥单选与记账录入修复

- 修复底部导航「更多」与「今日/待办箱/记账」同时高亮的问题：四个导航项改为同一层级的单选切换，任何时刻至多一项高亮；「更多」面板打开时其余三项取消高亮，点其余三项即切换页面并收起面板
- 修复「记一笔」面板打开时底部导航图标叠在「取消/保存记录」按钮上的问题：录入面板打开期间隐藏底部导航，关闭后自动恢复
- 数据结构无变化，桌面端不受影响；Android 可直接覆盖安装

#### v1.0.6 标签改单选与热力图恢复半年量

- 「标签」选择改为真单选：新建任务与编辑任务中均为与其他字段一致的单选下拉（「无标签」+ 已有标签），选中即生效；新建任务中「标签」与「重复」并排占一行
- 任务详情中「标签」显示与其他字段统一为纯文字（如「工作」/「无标签」），不再用方框胶囊
- 数据模型不变（任务表仍保留多标签能力），仅选择交互收为单选；已有多标签的任务在编辑保存时会收拢为一个
- 成长页热力图恢复为半年量：26 周 × 7 天共 182 格，桌面与手机一致；完成任务与目标记录点亮格子的逻辑保留

#### v1.0.5 标签选择改用下拉样式

- 新建任务与编辑任务的「标签」选择从多选列表框改为与其他字段（如优先级）一致的下拉样式：收起态显示已选标签（如「工作、健康」），展开后点选即勾选/取消、可同时勾选多个，选中项带 ✓ 标记
- 数据模型不变：任务仍支持多个标签，仅呈现方式与其他下拉字段统一

#### v1.0.4 任务表单统一与成长热力图改版

- 「新建任务 / 任务详情 / 编辑任务」三处统一瘦身：编辑任务移除「预计耗时、关联成长目标、完成贡献值、任务状态、精力要求、前置任务、提前提醒、可由智能排程/锁定排程」等低频字段；任务详情同步移除对应展示与「计划信息」区块
- 「重复」从「计划信息」取出，与「标签」一起并入详情的信息格子；详情与编辑的标签选择统一为多选列表框
- 今日页周历、月历的完成态与日历统一为「成就式」金色呈现：金色渐变底 + ✓ 金章，不再置灰划线
- 成长页热力图接入任务数据：完成任务与目标记录共同点亮格子，点击格子回看当天完成的任务与行动

#### v1.0.3 Android 版首发布

- 新增 Android 版：Tauri 2 构建，复用桌面全部功能；竖屏移动壳 + 底部导航 + 返回键/边缘手势返回语义
- 新增桌面 ↔ Android 数据同步：飞书云盘 JSONL 日志 + HLC 合并（离线优先，启动/回前台/手动触发，无服务器、无实时）
- Android 系统级提醒重写（精确闹钟 + 通知，桌面托盘路径不适用平台自动降级）
- 真机验收六轮反馈共 14 项呈现与交互问题修复（引导框间距、返回键语义、软键盘与手势、倒计时互斥等）
- 修复 Android 导入恢复必失败的问题：系统文件选择器返回的 content:// URI 现经 ContentResolver 读取
- release APK 自签名，版本号与桌面端统一管理；备份导出/导入兜底通道 Android 实测可用
