# 有秋 · Yield

**有秋** 是一款本地优先的个人成长与行动桌面应用。名字取自《尚书·盘庚》「若农服田力穑，乃亦有秋」——像农人服田力穑一样认真过好每一天，乃亦有秋，让每一份付出都有收成。

应用基于 Tauri 2 + React 构建，任务、账本、习惯与所有记录都保存在本机 SQLite 数据库中，不要求注册账号，也不依赖云服务。同一份代码同时构建 **Windows / macOS 桌面端**与 **Android 端**（APK 侧载，见下方「Android 版」）。

> 产品定位：面向个人的本地优先行动工具。不做多人协作、团队权限或企业级项目管理。

## 核心功能

侧栏按五个分组组织（分组典故见应用内悬停说明与设置页「命名缘起」）：

### 积微 · 每日行动

- **今日**：汇总今天截止的任务，逾期任务统一收进待办箱，今日页只呈现当日内容
- 今日时间轴中每个任务独占一行，悬停即可查看任务详情
- 新建任务时按所选日期与预计时长自动推荐当天第一个空闲时段
- 支持批量完成、改期、顺延，晚间逐项处理未完成任务
- **待办箱**：收纳无截止日期或非今日截止的任务，作为收集箱与整理入口
- **周清单**：按标签把本周任务归入「工作 / 生活 / 健康 / 学习」目标栏，当周概览、七列日历与完成率一目了然
- **周历**：日 / 周 / 月三档日历视图，检查时间冲突、安排跨天日程

### 观澜 · 收支总览

- 本地账本：记一笔、分类与账户管理、月度预算、软删除回收
- 金额可一键隐藏，适合截屏与演示场景
- 全部数据保存在本机数据库，随 JSON 备份完整导出

### 有恒 · 长期坚持

- **成长**：累计数量、数值变化、持续频率、累计时间、项目与自定义六类长期目标；任务完成、习惯打卡与专注时间可自动贡献进度
- 年度热点图展示过去一年的投入强度，可按目标筛选并点击日期回看
- 目标支持里程碑、暂停 / 恢复与手动记录；达成后自动生成成就
- **习惯**：每周目标、每日打卡与连续记录
- **复盘**：按自然周回看整体完成率、延期完成、高效时段与满勤天数，长期目标投入与每日行动对齐

### 百工 · 事务与知识

- **提醒**：单次提醒与多提醒组合，系统通知与通知中心；倒计时与循环提醒适合会议、发布、喝水、护眼等周期事项
- **备忘录**：富文本与 Markdown 双格式，支持置顶、归档与搜索
- **项目**：用颜色、目标、成功标准与截止日期组织相关任务，里程碑标记关键阶段

### 更多

- **纪念日**：公历、农历都能记，按远近排序，未来三十天内的单独列出
- **标签 / 回收站**：标签自动归类周目标；删除的任务先进回收站，可恢复
- **设置**：主题、提醒提前量、开机自启、无痕模式、备份与更新检查

## 任务与执行

- 优先级、状态、日期、起止时间、预计耗时与实际耗时
- 子任务、重复规则（每天 / 每周 / 每月 / 每周几多选 / 每月最后周五）、多次提醒、前置依赖
- 优先级、精力等级与灵活排程属性，帮助生成更合理的安排
- 任务历史记录，回看状态、时间与内容变化
- 完成任务需满足前置与子任务约束，防止漏做
- 专注会话基于绝对结束时间结算，休眠或卡顿后唤醒仍按真实经过时间扣减
- 桌面通知卡片展示已送达提醒，支持稍后提醒与跳转任务

## 提醒可靠性

- 关闭窗口会驻留托盘，不打断当前工作
- 最近的提醒（48 条、90 天内）会登记进操作系统级调度，**应用完全退出后仍由系统弹出**（需系统通知权限）
- 应用重新打开时受控补发错过的提醒：较早的只进入通知中心，避免集中弹窗
- 设置页可一键重新同步系统提醒、直达系统通知设置

## 桌面体验

- Windows 与 macOS 原生桌面应用
- 托盘常驻、开机自启
- 「清昼、晨曦玻璃、静夜、璃幕」四套完整视觉主题，并支持跟随系统自动切换
- 晨曦玻璃与璃幕以透明整窗外壳呈现氛围；Windows 圆角裁切干净，macOS 保留原生红绿灯
- 命令面板（`Ctrl/Cmd+K`）快速切换页面、执行常用操作

## 数据与备份

- 核心数据存储在本机 SQLite 数据库（`%APPDATA%\com.yunshan.yield\app.db`）
- 每次启动自动做数据库快照；开启自动备份后按周期导出完整 JSON（保留最近 10 份）
- JSON 备份覆盖任务、项目、习惯、提醒、倒计时、目标、纪念日与账本全部数据；恢复前先做快照，失败自动回滚
- CSV 可导出任务数据，便于在表格软件中加工
- 可从设置中检查数据库状态、打开数据目录并恢复历史快照
- 数据库结构只支持向前升级；不支持从高版本直接降级安装

## 数据与隐私

- 不要求账号、不依赖云服务；应用不提供云同步、在线协作或远程数据托管
- 无痕模式下系统通知标题与正文脱敏，避免锁屏或通知中心泄露任务内容
- 备份不包含任何密钥类数据
- 建议定期导出 JSON 备份，并将备份文件保存到独立磁盘或可信的个人同步目录

## 适合哪些人

- 希望把每天的计划、执行和复盘集中在一个应用中的个人用户
- 需要可靠桌面提醒、周期倒计时或专注计时的人
- 想通过长期目标和年度热点图看到持续投入的人
- 重视本地数据、希望离线使用且不愿注册账号的人

如果你需要多人协作、权限审批、甘特图或企业级项目管理，本项目并不以这些场景为目标。

## Android 版

Android 端复用桌面端全部数据层与业务逻辑，界面为移动壳：底部导航（今日 / 待办箱 / 记一笔 / 更多）+ 竖屏布局，无侧栏、命令面板与托盘。功能可用性如下：

| 功能 | Android 状态 |
|---|---|
| 今日 / 待办箱 / 日·周·月视图、建任务、完成、改期、顺延、优先级、批量管理 | ✅ 可用（触摸优化：行内长按弹操作面板，拖拽经手柄 `⋮⋮` 启动） |
| 记一笔（账本快速录入）、分类 / 账户 / 预算 | ✅ 可用 |
| 习惯打卡、周清单、复盘、成长目标、纪念日、备忘录、项目、标签、回收站 | ✅ 可用（小屏降级布局） |
| 系统提醒（任务到期提醒） | ✅ 可用（见下）；倒计时/循环提醒在应用运行时可用 |
| JSON 备份导出 / 导入 | ✅ 可用（导出写入应用数据目录 `backups/`；导入走系统文件选择器） |
| 四套主题 + 跟随系统深浅色 | ✅ 可用 |
| 自动备份、数据库快照、无痕模式 | ✅ 可用（重启式「恢复此版本」按钮仅桌面提供） |
| 托盘常驻、开机自启、命令面板、应用内版本更新 | ➖ 不支持（桌面专属，移动端隐藏） |

**提醒可靠性（Android）**：提醒登记为系统计划通知（AlarmManager），**应用退到后台或被回收后仍能准时弹出**；未授予「闹钟和提醒」精确权限时可能延迟数分钟（系统自动降级为非精确闹钟）。注意：从系统设置里「强制停止」应用会取消全部计划闹钟，重新打开应用后会补发错过的提醒。通知权限在首次启动时申请。

### Android 构建与安装

```bash
npm run tauri android build -- --debug --apk --target aarch64   # 真机 arm64
# 产物：src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk
```

在手机上允许「安装未知应用」后侧载安装即可（自用免费，未上架商店）。

## 下载与安装

当前版本 **v1.0.6**（见 `package.json` / `src-tauri/tauri.conf.json`）。本项目以本地构建分发为主：

```bash
npm run tauri build
```

> **Windows**：安装包不捆绑、不联网下载 WebView2。Windows 10/11 通常已随 Edge 自带运行时；极少数干净系统若无法启动，请自行安装 [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)。安装包未购买代码签名证书，浏览器与 SmartScreen 可能提示未知发布者——确认来源后选择「保留 / 仍要运行」。
> **macOS**：ad-hoc 签名、未经 Apple 公证；首次打开若被 Gatekeeper 拦截，请在「系统设置 → 隐私与安全性」中允许。
> **提醒**：关闭窗口会驻留托盘；完全退出后，已登记的到期提醒仍由系统弹出（需通知权限）。

## 开发

需已安装 Visual Studio Build Tools（MSVC）与 Rust。

```bash
npm install
npm run tauri dev
```

本地质量门禁（类型检查、全量测试、生产构建）：

```bash
npx tsc -b          # 类型检查（noUnusedLocals 开启）
npx vitest run      # 全量测试（24 个测试文件 / 127 个用例）
npx vite build      # 生产构建
```

若链接器冲突（Git 自带的 `link.exe`），复制 `src-tauri/.cargo/config.toml.example` 为 `config.toml`，并指向本机 MSVC 的 `link.exe`（该文件已加入 `.gitignore`，不会影响 CI）。

## 构建

```bash
npm run tauri build
```

### macOS（Apple Silicon / M 芯片）

无法在 Windows 上交叉编译出可用的 Mac 安装包。在 M 系列 Mac 本机打包：

```bash
npm install
python scripts/generate-dmg-assets.py   # DMG 背景图 724×464，需与 windowSize 660×400 配套
npm run tauri build -- --target aarch64-apple-darwin --bundles dmg
```

产物一般在：

- `src-tauri/target/aarch64-apple-darwin/release/bundle/dmg/`
- `src-tauri/target/aarch64-apple-darwin/release/bundle/macos/`
